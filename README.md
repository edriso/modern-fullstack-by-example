# Modern Full-Stack by Example

A junior-friendly handbook for the modern TanStack + gRPC + Drizzle + Turborepo stack. One page per topic, plain English, comparisons to React + Express + MySQL where it helps.

Built so you do not need a second tab open while you read.

## What's covered

| Group | Topics |
|---|---|
| Language | TypeScript fundamentals, Modern React |
| Frontend | TanStack Router, TanStack Start, StyleX |
| Workspace | Monorepos (pnpm + Turborepo), Biome, CI with GitHub Actions, Pre-commit hooks |
| Backend | Protocol Buffers + gRPC, BFF pattern, Auth (hashing + JWT + sessions), Error handling, Observability |
| Data | Drizzle ORM, Schema and relations, The N+1 query problem |
| Testing | Vitest, Playwright |
| Wrap-up | Big picture |

Every page follows the same shape:

- What it is, in two sentences.
- Why it exists and what older approach it replaces.
- Smallest working example.
- Comparison to a pattern you already know (Express, MySQL, CRA-style React).
- Common mistakes plus interview questions with answers.

## Run locally

```bash
pnpm install
pnpm run dev      # Vite dev server on http://localhost:5173
pnpm run build    # Static build to ./dist
pnpm run typecheck
```

The site itself is a React 19 + Vite + TanStack Router app. The route tree is generated automatically from `src/routes/**` by the TanStack Router Vite plugin.

## How it's organised

```
src/
├── main.tsx                  app entry
├── topics.ts                 single source of truth: order, groups, prev/next
├── routeTree.gen.ts          generated by the router plugin
├── components/
│   ├── Callout.tsx           note / tip / warn boxes
│   ├── CodeBlock.tsx         code with copy button
│   ├── Compare.tsx           two-column "old vs new" blocks
│   ├── Stub.tsx              placeholder used while a topic is being written
│   └── TopicLayout.tsx       shared topic page chrome + prev/next pager
├── routes/
│   ├── __root.tsx            layout: sidebar + main + responsive menu
│   ├── index.tsx             welcome page
│   └── <topic>.tsx           one file per topic
└── styles/
    └── global.css            design tokens + responsive layout
```

To add a topic:

1. Add an entry to `src/topics.ts`.
2. Create `src/routes/<slug>.tsx`.
3. The sidebar and the prev/next pager pick it up automatically.

## Stack used by this site

- React 19 + TypeScript 6 strict
- TanStack Router (file-based routing)
- Vite 8 build, with the TanStack Router plugin
- Plain CSS with custom properties (light + dark theme via `prefers-color-scheme`)
- No syntax-highlighter dependency. The `<CodeBlock>` is on purpose simple; swap in shiki/prism if you want.
